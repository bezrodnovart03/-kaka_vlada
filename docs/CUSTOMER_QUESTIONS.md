# Invoice Keeper — что реализовано и вопросы заказчикам

## Что хотели и что сделано

**Суть кейса:** администратор заводит регулярные платежи (аренда, подписки, серверы). За 3 дня
до срока бот пишет в Telegram-чат. Команда в веб-панели отмечает оплату и следит за просрочками.

### Обязательная часть

| Требование из ТЗ | Статус |
|---|---|
| Веб-панель с авторизацией | ✅ |
| Две роли: админ из `.env` и пользователи | ✅ |
| Платёж: название, сумма, валюта, дата, периодичность | ✅ ежемесячно, а также ежеквартально и ежегодно |
| У каждого периода своя дата и статус «Оплачено / Не оплачено» | ✅ |
| Просрочка со следующего дня после срока; при исправлении даты оплаты пересчитывается | ✅ |
| Бот за 3 дня до срока, без дублей, сразу — если платёж добавлен позже | ✅ |
| RUB / USD / EUR, итоги отдельно по каждой | ✅ |
| Все обязательные эндпоинты, OpenAPI и Swagger | ✅ |
| Запуск по README, `.env.example`, тестовые данные | ✅ ещё и одной командой через Docker |

### Дополнительные возможности (9 из 9)

| Возможность | Как сделано |
|---|---|
| Календарь оплат | Сетка месяца, итоги за месяц, экспорт `.ics` в Google / Apple / Outlook |
| Email-оповещения через SMTP | Письмо с `.ics`; в Docker — встроенный SMTP-сервер Mailpit |
| Webhook | JSON с подписью HMAC-SHA256 |
| Другие каналы | Apprise: Discord, Slack, ntfy, Matrix, Teams и др. |
| Логи | Вход и действия пользователей, доставка напоминаний; консоль и файл |
| Кнопка «Оплачено» в Telegram | Отмечает период оплаченным прямо из сообщения бота |
| Бюджет на месяц и год | Плановые расходы по каждой валюте |
| Чек или ссылка к оплате | Файл (PDF, фото) или ссылка у конкретного периода |
| Проработанный UX/UI | Фильтры, подсветка просрочек, тёмная тема, мобильная вёрстка |

Неясно другое: в ТЗ есть места, которые можно понять по-разному. Их мы решили сами, и правильно
ли — знают только заказчики. Об этом вопросы ниже.

## Вопросы заказчикам

> Здравствуйте! Мы команда, решающая кейс Invoice Keeper. Хотим уточнить несколько мест в ТЗ.
> В скобках — как сделано сейчас: если всё верно, достаточно ответить «ок».

### Напоминания

1. Напоминание одно за 3 дня до срока, или нужны повторные — в день срока и при просрочке?
   *(Сейчас одно на период, в окне «за 3 дня — день срока».)*
2. В какое время суток слать напоминания?
   *(Сейчас проверка раз в минуту, поэтому напоминание уходит в начале дня, когда срок попадает в окно.)*
3. Если платёж добавили со сроком в прошлом, нужно ли напоминание о просрочке?
   *(Сейчас прошедшие периоды создаются как просроченные, без сообщения.)*
4. Все напоминания идут в один общий чат из `.env`, или нужны личные — каждому пользователю?
   *(Сейчас один чат.)*
5. Кнопку «Оплачено» в Telegram может нажать любой участник чата?
   *(Сейчас да, оплата записывается на ник нажавшего.)*

### Платежи и периоды

6. Нужно ли редактировать платёж (сумму, дату)? В списке эндпоинтов только создание и удаление.
   Если сумма меняется, затрагивает ли это уже созданные периоды?
   *(Сейчас редактирования нет; у каждого периода сохраняется сумма на момент его создания.)*
7. Правило «нет такого числа — последний день месяца»: в следующем месяце возвращаемся
   к исходному числу?
   *(Сейчас да: 31 янв → 28 фев → 31 мар.)*
8. Что при удалении платежа происходит с неоплаченными прошлыми периодами — остаются просроченными?
   *(Сейчас прошлые периоды и история остаются, будущие неоплаченные удаляются.)*
9. Можно ли оплатить период заранее, за несколько месяцев вперёд?
   *(Сейчас дату оплаты в будущем указать нельзя, а оплатить период раньше срока — можно.)*
10. Оплата с опозданием — это всё ещё «просрочено» (в фильтре и итогах), или только пометка
    «оплачено с опозданием»?
    *(Сейчас второе.)*

### Роли

11. Администратор один (из `.env`) или их может быть несколько? Может ли админ назначить другого админа?
    *(Сейчас один, через панель создаются только обычные пользователи.)*
12. Может ли пользователь отменить оплату, которую отметил другой пользователь или админ?
    *(Сейчас может.)*

### Итоги и дополнительные возможности

13. Какие именно суммы нужны в `/payments/summary` и за какой период?
    *(Сейчас по умолчанию текущий месяц; для каждой валюты — план, оплачено, осталось, просрочено.)*
14. В бонусе «Календарь оплат» написано «итоги на дату по валютам». Имеется в виду сумма к оплате
    на конкретный день или состояние на выбранную дату?
    *(Сейчас календарь месяца, итоги за месяц и экспорт `.ics`.)*
15. Для email и webhook есть ли требования к получателям или формату?
    *(Сейчас email — на список адресов из `.env`; webhook — JSON с подписью HMAC.)*

    Подойдёт ли запуск через `docker compose`?
